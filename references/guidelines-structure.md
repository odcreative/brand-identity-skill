# Brand Guidelines Structure

The canonical section order, distilled from the **Radesk** 36-screen guideline (and consistent with Wheeler's *Designing Brand Identity*). Use it as the spine of `assets/brand-guidelines.html`. Scale up or down: **Essentials** ≈ sections 0–4; **Standard** adds 5–7; **Full** ships all.

Number sections `1.0, 2.0, …` and give each a divider screen, exactly like the reference.

## 0 — Cover & index
- **Cover** — "Brand Guidelines.", brand logo, version (`Version 1.0`), date.
- **Index / contents** — numbered list of sections with sub-items.

## 1.0 — Brand introduction
- **Introduction** — who the brand is, one confident paragraph.
- **Mission** — "We believe in the power of… to…" (present tense, active).
- **Vision** — "We envision…" (future the brand is building).
- **Values / personality** — 3–5 traits, each one line.
- *(optional)* Positioning statement, audience, tone of voice.

## 2.0 — Logo
- **Primary lockup** — the canonical logo, big, on brand ground.
- **Construction** — mark / horizontal / vertical built on a grid (one screen each for full sets).
- **Clearspace** — exclusion zone defined in `X` units (mark / horizontal / vertical).
- **Minimum size** — smallest print + screen sizes.
- **Lockup variants** — horizontal, vertical, submark, monogram, wordmark.
- **Colour variants** — full, reversed, mono, on brand colours.
- **Logo on backgrounds** — on tints, on photography, with scrim rules.
- **Misuse** — the Don't grid (stretch, recolour, rotate, shadow, low-contrast, rearrange).

## 3.0 — Colour
- **Primary** — 3–4 core swatches, each with Name · HEX · RGB · CMYK.
- **Secondary** — extended brights + tints.
- **Grayscale** — named ramp, near-white → black.
- **Logo in colour** — mark on each core colour.
- **Ratios & usage** — 60/30/10 guidance, do/don't pairings.
- **Accessibility** — approved text/background contrast pairs.

## 4.0 — Typography
- **Primary typeface** — family, big `Aa`, all weights, alphabet.
- **Type scale** — named steps with px/pt and role.
- **In-use** — a real headline + paragraph set in the brand.
- **Pairing / secondary** — body or label family, if any.
- **Setting rules** — tracking, leading, case, alignment.

## 5.0 — Iconography, pattern & graphic language
- **Icon system** — construction logic, grid, stroke, sample set (Ecovine's produce set is the model).
- **Pattern** — the icons/marks tiled into a repeatable pattern for packaging and backgrounds.
- **Graphic devices** — any signature shapes, the "orbital text" ring, badge/seal, dividers.

## 6.0 — Imagery & art direction
- **Photography style** — subject, light, colour treatment, do/don't (Ecovine bright & fresh vs. Dusk dark & moody).
- **Logo-over-image** rules — placement, scrim, tint.
- **Illustration / 3D** direction if used.

## 7.0 — Applications
- **Icon / app** — app icon, favicon, macOS/iOS, social avatars.
- **Stationery** — business card, letterhead, envelope, comp slip.
- **Digital** — website header, app UI, email signature, social profile/templates.
- **Merch / apparel** — t-shirt, cap, tote, uniform.
- **Signage / environment** — storefront, 3D sign, wayfinding, window graphics.
- **Packaging** — boxes, bags, labels, sleeves (if relevant).
- **Advertising** — billboard, city/OOH, digital ads.

## 8.0 — Governance (optional, for larger clients)
- Versioning, file formats & where to get assets, contact for brand questions, ©/™ and legal.

---

### Authoring rules
- **One idea per screen.** A guideline is a slideshow, not a poster.
- **Divider screens** carry only the big section number + title (`3.0 / Brand Colors.`).
- Lots of white/anchor space; the content is the logo and the rules, not decoration.
- Every rule shown, not just told — pair each instruction with a visual example (and, on misuse, a red-crossed counter-example).
- Keep copy terse and declarative. Label eyebrows in tracked uppercase.
- Landscape 16:9 canvas per screen for on-screen + PDF export.
